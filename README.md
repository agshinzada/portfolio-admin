
# agshin.dev - Admin Dashboard 


This admin panel powers the management side of the agshin.dev project. It allows seamless creation, editing, and deletion of content through a user-friendly interface. Built with modern technologies, the panel is designed to provide a fast, intuitive, and efficient experience for maintaining the site's content and structure.

  


## Tech Stack

- **React.js** with **Typescript** and **React Router**: For building the frontend and managing routes.  
- **Tailwind CSS**: Utility-first CSS framework for fast styling and responsive layouts.
- **ShadcnUI**: A customizable component library built on top of Tailwind CSS.
- **React-hot-toast**: For clean and customizable toast notifications.
- **Zustand**: A minimalistic state management library for managing global state.
- **Lucide icons**: An open-source backend as a service (BaaS) used as the project's real-time database and authentication provider.

## Features

- **Projects Page**
  - Displays a list of all personal or professional projects added by the admin.
  - Allows creation, editing, and deletion of project entries with details like title, description, tags, and links.

- **Skill Page**
  - Showcases the developer’s technical and soft skills in categorized sections.
  - Enables skill group management and individual skill item updates.

- **Experience Page**
  - Lists work experiences, internships, or significant contributions.
  - Admin can manage each entry’s role, company, duration, and description.

- **Images Page**
  - Stores and manages uploaded images used across the website.
  - Provides image previews and delete functionality.

- **Setting Page**
  - Contains general settings for the portfolio site, such as name, title, about section, contact info, and social links.
  - All fields are editable for quick customization.

- **Login Page**
  - Secure authentication page for admin access.
  - Prevents unauthorized entry to the admin panel and dashboard routes.


## Run Locally

Clone the project

```bash
  git clone https://github.com/agshinzada/portfolio-admin.git
```

Go to the project directory

```bash
  cd portfolio-admin
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```
